## 製品概要
**WinCook** はウィンク操作と AI 会話で料理を革新するクッキングアプリです。

ウィンクするだけでレシピをスクロールし、手が汚れていても操作可能。  
さらに、レシピを理解した AI と「この調味料がないときは？」「もっと濃い味にするには？」といった会話ができ、  
まるで料理上手な友人と一緒に調理しているような体験を提供します。


### 背景(製品開発のきっかけ、課題等）
料理中の「あるある」な困りごと。手がベトベトなのにレシピを見たい時、スマホを触れずにイライラ。  
「この調味料がない時はどうしよう？」と思っても、手を洗って検索する間に料理が焦げそうになる。  
料理って本来楽しいはずなのに、デジタルデバイスとの相性の悪さで、せっかくの料理体験が台無しになってしまう。  
そんな現代の料理の「不便」を「革新」に変えたくて、**WinCook** が生まれました。

### 製品説明（具体的な製品の説明）
### 特長
#### 1. ウィンクによるレシピ遷移
- 手が汚れていても、ウィンク一つでレシピをスクロール。料理中の「手を洗わなきゃ画面が触れない」ストレスから完全に解放されます。
#### 2. AI によるリアルタイムアシスト
- 「この調味料がないときは？」料理中の疑問を声に出すだけで、AIが瞬時に答えてくれる。まるで料理上手な友人と一緒に作っているような安心感。
#### 3. スケール可能な堅牢なアーキテクチャ
- Go + Supabaseによる高性能バックエンドで、多数のユーザーが同時利用しても快適。将来の機能拡張にも柔軟に対応できる設計です。

### 解決出来ること
- 手が汚れた瞬間に感じる、あの絶望感を解消
  - 肉をこねている手、油まみれの指、小麦粉だらけの掌。そんな時に限ってレシピの次を見たくなる。  
    もうスマホを汚す心配も、手を洗いに行く面倒もありません。
- 料理中の「わからない！」パニックを瞬時に解決
  - 「醤油がない！」「この野菜、いつまで炒めるの？」料理中に湧き上がる疑問や不安。  
    検索している間に料理が焦げる恐怖から解放され、いつでも頼れるAIアシスタントが隣にいる安心感を提供します。

### 今後の展望
- アプリ内での食材購入機能
  - レシピを見て「この調味料ない！」と気づいた瞬間に、ワンタップで注文完了。買い物の手間を完全に省略します。
- Android 版
  - iOS の革新的体験を Android にも展開。より多くの人に「料理の新しい楽しさ」を届けます。 
- レシピ API の追加
  - 外部レシピサービス連携で、無限に広がる料理の世界へ。あなた好みのレシピが必ず見つかります。
- Custom Adapter を用いた AI のチューニング
  - あなたの料理レベルと好みを学習し、完全パーソナライズされた「専用料理パートナー」に進化します。

### 注力したこと（こだわり等）
- 未来の料理体験を、今ここに
  - iOS 26の最新技術を駆使し、「ウィンクで操作」という SF映画のような体験を現実に。  
    単なるアプリではなく、料理という日常を劇的に変える「体験革命」を起こしました。
- 成長を見据えた技術選択
  - 多くのユーザーに愛され続けるアプリを目指し、スケーラビリティを最優先に設計。  
    今日の快適さだけでなく、明日の拡張性も確保した、長期的視点での技術投資を実現しています。

## 開発技術
- iOS：Swift 5+ / SwiftUI
- バックエンド：Go

### 活用した技術
- クラウド：Supabase
- Face Tracking：Vision Framework

#### API・データ
- ローカルDB：SwifData
- クラウドDB：Supabase
- API Server：Go

#### フレームワーク・ライブラリ・モジュール
- UIKit
- SwiftUI
- Speech Framework
- 音声：AVFoundation（TTS）
- AI：FandationModels
- Face Tracking：Vision Framework

#### デバイス
* iPhone / iOS 26.0以上 (appleintelligence搭載端末推奨)

### 独自技術
#### ハッカソンで開発した独自機能・技術
- wink判定
  - Vision Framework の目の高さトラッキング API を活用し、目の高さの変化からウィンク動作を検知する仕組みを開発。  
    料理中の手が使えない状況でも、自然な動作でレシピを操作できる新しい体験を生み出しました。

- AI友達料理サポート
  - Speech Framework で常時音声を文字起こしし、特定のキーワードを検知すると Apple Intelligence にプロンプトを送信する仕組みを構築。  
    料理中の疑問や不安を声に出すだけで、リアルタイムでサポートを受けられる環境を実現しました。
