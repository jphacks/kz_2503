# 要件定義（No-Hand Recipe / v1）

## 目的・ゴール

- 目的：調理中にレシピの確認のために手を洗い、端末を操作する手間を無くす。
- ゴール：料理の効率化・料理初心者のハードルの低下。

## ペルソナ・利用シーン

- メインターゲット
    - 主婦
- ペルソナ：18歳 , 女性 , 大学生 , 一人暮らしを始め、料理に挑戦する。
- シーン：
    1. アプリを起動し、レシピを検索 & 選択
    2. 端末をスタンドに設置 → ノーハンドON → 前面カメラ有効
    3. ノーハンドで料理を行い、ウインクを用いて、レシピの前後を移動する
    4. 手順に紐づくタイマーを起動、完了で自動アナウンス

# 機能要件（段階別）

## P0（必須MVP）

1. ログイン・新規登録画面のチュートリアル以外
2. 探す画面のヘッダー、検索
3. レシピ画面のハンズフリーモード、料理内容
4. ウィンク検出によるページ送り/戻し（右=次、左=戻る・固定）

## P1（信頼性・使い勝手の基盤）

1. 探す画面のレシピ追加ボタン
2. 記録画面のお気に入り機能
3. レシピ追加画面のヘッダー、タイトル、材料、作り方、説明
4. レシピ画面の AI 会話
5. 通知画面
6. ログイン・新規登録画面のチュートリアル

---

## P2（体験の厚み・学習コスト低減）

1. 探す画面の人気のレシピ、カテゴリ
2. 記録画面の自分の料理フィルター、閲覧履歴
3. ユーザー画面
4. 設定画面

---

## P3（拡張・最適化）

1. 探す画面の AI 検索
2. 献立画面
3. レシピ追加画面の AI サポート、写真追加、コツ・ポイント追加
4. レシピ画面の進捗バー、ボタン各種
5. 多言語対応
6. 検索履歴

## 技術要件

- iOS：Swift 5+ / SwiftUI
- 機械視覚：Vision（顔/目トラッキング、ウィンク推定）
- 音声：AVFoundation（TTS）
- ローカルDB：SwifData
- 外部API：利用しない（Spoonacular/Edamam等は不使用）
- DB・認証：Supabase
- バックエンド：Go
